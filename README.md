# refugio-mapas

Archivos de mapa y de puntos de referencia para la app Refugio (paquetes que se descargan aparte de la app).

- Datos: © colaboradores de [OpenStreetMap](https://www.openstreetmap.org/copyright), licencia [ODbL](https://opendatacommons.org/licenses/odbl/).
- Este repositorio solo guarda datos. No contiene código de la app ni datos de usuarios.
- Los archivos se publican como assets de las Releases, con su SHA-256 indicado en cada una.
